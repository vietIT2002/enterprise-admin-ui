# Northwind Distribution - Order desk

Product: Northwind Distribution, an order desk for a regional wholesale distributor. Clerks key in orders taken by phone and email.
Roles: order clerk (creates and edits orders), warehouse lead (reads orders), finance (reads totals).
Locale: en-US; currency USD; dates MM/DD/YYYY.
Accent: blue-700 (`#1d4ed8`).

## Status vocabulary

| Status | Tone |
|---|---|
| Pending | info |
| Shipped | info |
| Delivered | success |
| Cancelled | danger |

An order is created as Pending when it is saved.
