# Northwind Distribution - Orders

Product: Northwind Distribution, an order desk for a regional wholesale distributor.
Roles: order clerk (creates and tracks orders), warehouse lead (reads orders), finance (reads totals).
Locale: en-US; currency USD; dates MM/DD/YYYY.
Accent: blue-700 (`#1d4ed8`).

## Status vocabulary

| Status | Tone |
|---|---|
| Pending | info |
| Shipped | info |
| Delivered | success |
| Cancelled | danger |

## Conventions

- Rows: 52px (`h-[52px]`); Customer cell shows name with the email below it as a link; keep.
- Money is right-aligned with tabular figures.
